### Anti-Patterns Verdict

**LLM assessment**: Does NOT scream "AI made this." The OKLCH color system, asymmetric grid ratios, clamp-based fluid typography, and semantic token architecture show genuine craft. Two patterns are recognizable as templates: the proof-stack right-sidebar layout and the eyebrow labels on every project card.

**Deterministic scan**: Zero violations across all detector rules.

### Priority Issues

**P0 — Hero cognitive overload**: ~9 interactive targets + ~150 words on first paint. Hiring managers scan in ~5s. Reduce proof-stack to 2 cards, make headline + CTA the focal point.

**P1 — About section repeats the hero**: Same thought twice ("I build frontend systems..."). User learns nothing new.

**P1 — Contact section is 68vh of sparse whitespace**: Journey ends anticlimactically (Peak-End rule violation). Add closing statement or CTA.

**P2 — Project-index eyebrows add noise**: Labels like "Agent workspace" are redundant — titles already communicate the category.

**P2 — No hamburger menu on mobile**: Header stacks vertically at 680px, wasting space. "Email me" disappears.

### Persona Red Flags

**Jordan (First-Timer)**: Hero overload, unclear primary CTA, exposed phone number.

**Riley (Stress Tester)**: No error/loading states, JS failure breaks features, no 404 page.

**Casey (Mobile User)**: No hamburger, Email me hidden at 680px, proof-stack consumes mobile real estate.
